# FlightCostApp

**Сколько стоит авиарейс и при каком чеке он выходит в ноль — с источником у каждого числа.**

Вы выбираете маршрут, тип самолёта и загрузку. Программа считает рейс по статьям — топливо, сборы аэропортов, аэронавигация, владение, обслуживание, экипаж — и показывает, откуда взята каждая цифра: из опубликованного тарифа, из расчёта или из допущения, которое стоит заменить своим.

## Запуск за пять минут

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/BormatovD/FlightCost.git
cd FlightCost
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

Собрать справочники — аэропорты, ставки, курсы, типы самолётов. Первый раз занимает несколько минут:

```bash
fca refresh --all
```

Тарифы и курсы, разобранные из документов, программа сама не принимает — их подтверждает человек. Посмотреть, что ждёт, и принять:

```bash
fca review
fca review --accept <номер>
```

Повторить `--accept` для каждого номера из списка.

Открыть витрину в браузере:

```bash
fca serve
```

и перейти на **http://127.0.0.1:8000**.

Часть источников требует своих ключей (цены билетов, наблюдения полётов) — в расчёте они будут помечены как «не подключены». Без них всё работает, просто без этих данных. Что собрано, а что нет, покажет `fca status`.

## Первый расчёт из командной строки

```bash
fca econ FRA BCN --lf 0.82 --fare 95
```

Франкфурт — Барселона на A320, загрузка 82%, средний чек 95 евро. Ответ — стоимость рейса по статьям и безубыточный чек.

Подробный разбор с формулами и источником каждого шага:

```bash
fca explain FRA BCN --lf 0.82 --fare 95
```

Все команды — в [docs/шпаргалка.md](docs/шпаргалка.md).

## Чем это отличается от калькулятора

**У каждого числа есть происхождение.** Разбор помечает каждую цифру: взята из документа аэропорта или регулятора (со ссылкой), посчитана, задана вами — или это заготовка. Сверху видно, какая доля ответа держится на заготовках. На Франкфурте — Барселоне сейчас это около 40%: ставки лизинга, обслуживания и экипажа закрыты у перевозчиков, и их стоит заменить своими.

**Программа умеет отвечать «нельзя».** Если самолёт не долетает, не поднимает столько пассажиров или для типа нет данных о расходе — вы увидите причину, а не правдоподобную цифру.

**Расчёт воспроизводится.** Справочники хранят историю: расчёт, сделанный в марте, в декабре даст то же число — `--as-of 2026-03-01`.

## Что внутри

- **44 аэропорта** с разобранными тарифами: Европа, Россия, Китай, Индия, Япония, Ближний Восток. Остальные — по параметрической оценке с явной пометкой.
- **Аэронавигация** по опубликованным ставкам EUROCONTROL, России, Китая, Казахстана, США и других — с разбивкой маршрута по зонам.
- **37 типов самолётов** с физикой расхода топлива, плюс свои типы: можно завести самолёт, которого нет в справочнике, — например Ту-214.
- **Две внешние проверки:** сборы Франкфурта сходятся с калькулятором аэропорта до цента, аэронавигация — с отчётностью Ryanair с отклонением 0,4%.

## Чего здесь нет

**Модели спроса.** Сколько пассажиров полетит — вы задаёте сами. Поэтому главный ответ не «маржа 8%», а «рейс выходит в ноль при таком-то чеке».

**Закрытых коммерческих ставок.** Стоимость лизинга и обслуживания продаются за деньги; здесь они — заготовка, которую вы заменяете своими цифрами.

---

## Как помочь

Самое ценное — **тарифы аэропортов**. Если у вас есть опубликованный документ с аэропортовыми сборами, которого здесь нет, — откройте issue со ссылкой на него. Ошибка в числе — тоже issue: у каждого числа указан источник, и проверить его просто.
