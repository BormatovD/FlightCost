# Каталог типов ВС

Решение 223. Один файл — один тип, формат как у своих типов (`flightcostapp/parsers/aircraft_user.py`)
плюс блок `meta`: статус программы, вид данных (`official` · `announced` · `projected`),
дальность и полосы, источник каждого поля (`field_sources`), пробелы (`gaps`) и расхождения (`doubts`).

Загрузка: `fca refresh --only aircraft_catalog` → `fca review` → принять.

- Тип без полей расчёта (`mtow_t, oew_t, fuel_capacity_t, seats_max, span_m, cruise_mach, cruise_alt_m`)
  заводится карточкой: виден в списке, в расчёт не выбирается, пробелы названы.
- Ключи не совпадают с типами openap (тест `tests/test_catalog.py`).
- Крейсерская высота, если издатель её не назвал, — эшелон класса, помечено в `meta.assumed`.
- Собрано 17.10.2026 по открытым источникам; обзор для проверки — `каталог-типов-ВС.xlsx` (вне репозитория).
