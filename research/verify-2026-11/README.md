# Сверка модели на сетях Frontier и Southwest (ноябрь 2026)

Статья: «Проверил свою модель экономики рейса на Frontier и Southwest».

## Что сделано

1. Сети 2025 года из BTS T-100 Segment (класс F) прогнаны через калькулятор
   пара × тип ВС с фактическими креслами и загрузкой: Frontier 204 тыс.
   вылетов, Southwest 1,41 млн (`bin/fleet_check.py`). Цена топлива — из
   годовых отчётов ($2,47 и $2,41 за галлон), курс 1,13 USD/EUR (ЕЦБ, 2025).
2. Сравнение по статьям: топливо и аэропорты — 10-K, ТОиР и лётный экипаж —
   Form 41 P-5.2 по типам, блок-часы — T-100 (`out/items.json`).
3. Правки (патч «Сверка на сетях США»): аэронавигация FAA только для
   транзита; сборы аэропортов США k = 0,86 по JetBlue (Alaska Air Group —
   проверка порядка); экипаж США × 2,88 по Form 41 семи перевозчиков вне
   контрольной выборки; руление по аэропортам из T-100.
4. Доходная часть — свёртки DB1C июль 2025 — июль 2026 с разбивкой по
   перевозчикам (`charts/`).

Правило проверки: всё подобранное подбиралось по перевозчикам вне
контрольной выборки (JetBlue, Alaska, Hawaiian, Horizon, Spirit, Allegiant,
Sun Country); Frontier и Southwest — только проверка.

## Итог по статьям (ошибка модели к отчётности, до → после)

| Статья | Frontier | Southwest |
|---|---|---|
| Топливо | −5 → −5 % | −9 → −9 % |
| Блок-часы | −2 → −1 % | +8 → +7 % |
| ТОиР | −8 → −7 % | +8 → +8 % |
| Экипаж (пилоты × 1,56) | −45 → +58 % | −67 → −5 % |
| Аэропорты | +34 → +14 % | +66 → +29 % |
| Аэронавигация, млн USD | +75 → +17 | +406 → +48 |

## Что не получилось

- Экипаж: один множитель на страну не ловит перевозчика — у Frontier лётный
  экипаж на 14–39 % дешевле, чем у сравнимых компаний. Ставка экипажа —
  вход по перевозчику.
- Руление Southwest: 19–21 мин на рейс против 25–26 по оценке, собранной на
  других перевозчиках в тех же аэропортах, — свойство перевозчика.
- Множитель «средний чек к минимуму» по типу перевозчика не лучше
  ступеньки 1,2/2,0 (медианная ошибка 30/17 % против 28/16 %,
  `charts/conv_test.py`) — в код не внесён.

## Ограничения

- Уровни ТОиР и владения раньше сверялись с той же Form 41 2025 года
  (решение 186) — совпадение по ним частично проверка на тех же данных.
- Бортпроводники в Form 41 по типам не отчитываются: полный экипаж —
  пилоты × (1 + 0,56), доля кабинного экипажа по структуре ACMG.
- Southwest владеет большей частью парка: бухгалтерское владение
  ($1,6 млрд) и экономическое в модели ($3,0 млрд) — разные величины.
- Сырые файлы (T-100, DB1C, база) в репозиторий не кладутся; скрипты в
  `charts/` ждут свёртки DB1C в соседних папках рабочей копии.
