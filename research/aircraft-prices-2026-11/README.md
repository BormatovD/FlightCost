# Исследование стоимости самолёта

Первый черновик от 11.11.2026: каталог, рыночная оценка, возраст и месячный лизинг.
Статья остаётся `draft: true` до проверки выводов на модели владельцем и решения о публикации.

## Воспроизвести

Из корня репозитория, в Python-окружении проекта. Для пересборки HTML нужен
Python 3.12 или новее: сборщики статьи используют вложенные многострочные f-строки.
Готовые HTML уже включены в патч.

```bash
python research/aircraft-prices-2026-11/analyze.py
python research/aircraft-prices-2026-11/history.py
python research/aircraft-prices-2026-11/lease_economics.py
python research/aircraft-prices-2026-11/model_reference.py
python research/aircraft-prices-2026-11/lease_calibration.py
python research/aircraft-prices-2026-11/build_report.py
```

Анализ работает без сети по сохранённым входам. Сборка создаёт `report.html` (RU),
`report.en.html` и `report.de.html`. Расчёт примера использует `flightcostapp.fleet`
и датированный снимок `research/_fx.json`; контрольные суммы входов записаны в результате.

Повторно извлечь возрастные колонки AVAC можно отдельной командой:

```bash
python research/aircraft-prices-2026-11/analyze.py \
  --refresh-avac --cache-dir /tmp/fca-aircraft-prices-avac
```

Каталог кеша должен находиться вне репозитория. Команда использует сохранённые там страницы
или скачивает их; сырые HTML не входят в исследовательский набор.

## Файлы и границы набора

- `SPEC.md` — вопросы исследования и правила сопоставления.
- `analyze.py` — покрытие, каталог к оценке, точные пары лизинга и стоимости, возрастные
  срезы, постоянный состав типов по годам и расчёт стоимости условного рейса.
- `out/summary.json` — расчётные результаты и контрольные суммы входов.
- `out/additional_observations.json` — отдельная исследовательская выписка.
- `out/sources.json`, `trace/prices.jsonl` — источники, даты, места в документах,
  ограничения и короткие цитаты для проверки.
- `verify/` — независимый пересчёт, проверка источников и журнал её охвата.
- `build_report.py`, `report*.html` — сборщик статьи и три языковые версии.
- `report_extensions.py` — восемь графиков по сегментам и раздел экономики лизинга.
- `lease_economics.py`, `out/lease_economics.json` — условная сделка, стоимость актива,
  кредит, денежные потоки собственного капитала, чувствительность и остаточный риск.
- `LEASE_METHOD.md`, `trace/lease_economics.jsonl` — границы финансовой модели и первичные
  источники о договорах, платежах, возврате и учёте.

Исходный справочник содержит **167 принятых наблюдений по 22 типам**. Дополнительный
набор содержит **119 исследовательских наблюдений**: 102 возрастные ячейки AVAC
2016–2020 годов и 17 свежих ориентиров IBA (15 из авторской публикации ICLG и 2 из
официального подкаста). Это разные состояния данных; 119 строк не прибавляются автоматически
к принятому справочнику.

Публикация IBA относится к **2026-Q1**. Квартал сохранён как квартал, без выдуманного
месяца. Возраст, модификация и базис оценки сохраняются отдельно. Середина диапазона —
допущение сценария, а не наблюдаемая средняя цена сделки.

**Автоматического импорта нет.** Анализ и сборка не меняют `data/prices`, ставки
калькулятора и правила приёма черновиков. Новые данные требуют отдельного решения о
включении в справочник и корректного сохранения точности дат.

## Проверка

Обычная офлайн-сборка использует окружение проекта. Независимые исследовательские проверки
имеют дополнительные зависимости: `lxml` для HTML, `pandas` для независимого чтения таблиц,
`pdfplumber` / `pdfminer.six` для альтернативного чтения PDF. Повторное извлечение исторических
графиков сборщиком использует `PyMuPDF`. Это инструменты исследования; устанавливать их
в производственную службу агента или калькулятор не требуется.

```bash
python research/aircraft-prices-2026-11/verify/verify_lease_economics_0056.py
python research/aircraft-prices-2026-11/verify/verify_model_reference_0056_v2.py \
  --openap-root "$(python -c 'import importlib.util; print(next(iter(importlib.util.find_spec("openap").submodule_search_locations)))')"
python research/aircraft-prices-2026-11/verify/verify_report_0056_v2.py
```

Независимая проверка завершена: пересчитаны исходные показатели, все 102 дополнительные
ячейки AVAC, 17 свежих ориентиров, 62 возрастных отношения, постоянный состав типов,
пары лизинга и стоимости, сквозной пример и цитаты. Итог — `pass_with_scope_limits`
в `verify/summary.json`; подробный охват и оговорки находятся в соседних файлах.
Этот статус подтверждает проверенные факты и арифметику; он не заменяет проверку
будущей возрастной модели и решение владельца о публикации.

## Исторические графики по сегментам — дополнение 0056

`history.py` готовит отдельные панели стоимости борта и месячного лизинга для четырёх
сегментов. В них **451 наблюдение по 15 типам**: 180 ячеек таблиц AVAC, 249 приблизительных
считываний опубликованных исторических кривых TrueNoord и 22 числовых ориентира из текстов.
Эти 451 строка частично повторяют исходные принятые и исследовательские записи: это новая
проекция для графиков, а не ещё 451 независимое пополнение справочника.

Из корня репозитория, без сети:

```bash
python research/aircraft-prices-2026-11/history.py
python research/aircraft-prices-2026-11/build_report.py
```

Повторное извлечение исходных HTML и PDF требует PyMuPDF и окружения проекта:

```bash
python research/aircraft-prices-2026-11/history.py \
  --refresh --cache-dir ../fca-price-history-cache
```

Кеш должен находиться вне репозитория. Уже скачанные файлы используются повторно;
изменение контрольной суммы PDF останавливает извлечение до новой проверки калибровки.
Свежие текстовые ориентиры закреплены в коде и проверяются по журналу и источникам.

| Сегмент | Типы |
|---|---|
| Турбовинтовые | ATR 42-600, ATR 72-600, Dash 8-400 |
| Региональные реактивные | E175, E195-E1, E195-E2, CRJ900 |
| Узкофюзеляжные | A320neo, A321neo, 737-800, 737 MAX 8 |
| Широкофюзеляжные | A330-200, A350-900, 777-300ER, 787-9 |

Файлы дополнения:

- `out/segments_history.json` — нормализованные наблюдения, отдельные серии, источники,
  покрытие и отсутствующие годы для каждого типа, возраста и вида цены.
- `out/history_source_observations.json` — извлечённые ячейки AVAC и точки исторических
  графиков, с исходными флагами комплектации и контрольными суммами источников.
- `out/history_chart_extraction.json` — калибровка осей, номера векторных путей и координаты,
  позволяющие повторить считывание каждого PDF.
- `trace/history.jsonl` — журнал источников, ограничений, исключённых прогнозов и недоступных
  отчётов; короткие цитаты не дублируют прежний журнал.
- `verify/history*.json` — отдельная независимая проверка дополнения 0056.

Основные панели используют **новый борт**; подержанные самолёты сохраняются отдельно.
Dash 8-400 не получает искусственного нового ряда после 2021 года. Время сохраняет
точность источника: год, месяц или квартал. AVAC, TrueNoord, IBA и Oriel не соединяются
в одну линию с общим базисом; меняющиеся спецификации тоже разделяются.

Оцифрованные точки приблизительны: стоимость округлена до 100 тыс. USD, месячный лизинг —
до 1 тыс. USD. Допуск чтения указан отдельно и **не изображается как рыночный диапазон**.
Границы `amount_low_usd`/`amount_high_usd` различаются только там, где источник действительно
публикует диапазон. Цена самолёта здесь — оценка рынка, не раскрытая цена сделки.

Новые ATR 42/72-600 имеют историю 2016–2023, новый Dash 8-400 — 2016–2021; более свежий
турбовинтовой отчёт найден только за формой запроса. В остальных сегментах покрытие
неравномерно: AVAC даёт основу до 2020 года, TrueNoord — часть 2021–2024, IBA и Oriel —
отдельные ориентиры 2026 года. Полный перечень пробелов находится в JSON; пропуски не
заполняются нулями или прогнозами.

Исходные `analyze.py` и `out/summary.json` сохраняются. Исследование остаётся `draft: true`;
исторические панели, как и исходные 119 дополнительных записей, **не импортируются**
в `data/prices` и не меняют ставки калькулятора автоматически.

Независимая проверка дополнения завершена: сверены 180 ячеек AVAC, все 249 считываний
исторических кривых и 11 новых текстовых ориентиров; ещё 11 ориентиров унаследованы из
проверенного набора 0055. Проверяющий отдельно открыл источники, повторил извлечение
другим PDF-парсером и подтвердил все 11 новых коротких цитат. Подробности —
`verify/history_0056.json` и `verify/history_trace_0056.json`. Сохраняются оговорки о
графической точности, составе оценщиков, возрасте и неполноте современных рядов.

## Схемы сделки и текущая заготовка — 0056-v2

Это замена неприменённого 0056 от той же базы, а не следующий патч поверх него.
`deal_flow.py` показывает три этапа проверенного численного примера: покупку, месячные
платежи и продажу. На стрелках получатель, сумма, период и условия; на каждом этапе
сходится денежный баланс. Кредит на 10 лет под 6% эффективных годовых амортизируется
по 15-летнему графику: остаток после 120-го платежа погашается при продаже. Возврат
основного долга и денежный поток акционера не называются прибылью. Депозиты,
технические резервы и компенсации показаны отдельно без выдуманных сумм.

`model_reference.py` читает заготовку из `flightcostapp.fleet`, публичные параметры
самолётов и пересчёт исторических долларов из `flightcostapp.seo`. Результат —
`out/model_reference.json`, методика — `MODEL_REFERENCE.md`, происхождение —
`trace/model_reference.jsonl`. Для всех 15 типов добавлены штрихпунктирные кривые
на четыре графика лизинга. Модельной цены покупки в коде нет; обратный расчёт из
аренды не выдаётся за действующую модель цены ВС.

База: `L = L0 × (MTOW / 78 т)^1.10`, `L0 = 345000 EUR/мес.` для `new`,
`200000 EUR/мес.` для `current`. Отдельного коэффициента сегмента, числа кресел
или непрерывной возрастной кривой здесь нет. Публичный default совпадает с сырой
параметрикой у всех 15 типов; возможные частные серверные overrides этим не проверены.
Шесть типов описывают новый борт; девять, включая ATR 42/72-600, — около 12 лет.
Их сравнение с новыми рыночными ВС явно отмечено как разновозрастное.

На графике используется существующая условность `1.16 USD/EUR` и CPI-U с базой
октябрь 2026; индекс 2026 экстраполирован последним годовым ростом после 2025.
Это сегодняшняя формула в номинальных долларах каждого года, не исторический
прогноз и не фактическая котировка. Валютный переключатель статьи использует
свой датированный снимок `1.113 USD/EUR`; два назначения курса подписаны отдельно.

Независимые аудиты новой версии — `verify/*_0056_v2.json`: повторная сверка истории,
формулы и всех 165 годовых модельных точек, трёх языковых HTML, денежных стрелок
и балансов. Старые `*_0056.json` сохраняют результат предыдущей редакции и не
считаются проверкой изменённого HTML. Визуальная проверка выполнена статическим
рендером; интерактивность в живом браузере в этом окружении не проверялась.

## Редакция 0057

Главные панели показывают восемь типов: AT46/AT76, E75L/E295, A20N/A21N, A359/B789.
Покупная цена раскрывается отдельно; исходный набор 15 типов и 451 наблюдение сохранён.
`model_cards.py` строит правые карточки с параметрами модели и датированной поправкой.
`lease_calibration.py` и `CALIBRATION_METHOD.md` описывают коэффициенты пяти новых типов;
для трёх несовпадающих возрастных баз поправки нет. Середина диапазона — сценарный выбор,
не независимый прогноз. У модели графика и примера рейса разные явно показанные FX-конвенции.

Общий текстовый контейнер исправлен в `_report.py` и во всех тридцати HTML-версиях статей.
Схемы сделки и рыночные исходники не изменены.

Новые независимые аудиты: `verify/calibration_0057.json`, `verify/display_0057.json`.
Они подтверждают источники, арифметику и структуру отображения; не подтверждают способность
датированного k предсказывать будущие ставки. Старые аудиты относятся к своим редакциям.

```bash
python research/aircraft-prices-2026-11/lease_calibration.py --check
python research/aircraft-prices-2026-11/build_report.py
python research/aircraft-prices-2026-11/verify/verify_display_0057.py
```
