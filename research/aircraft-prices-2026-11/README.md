# Исследование стоимости самолёта

Первый черновик от 11.11.2026: каталог, рыночная оценка, возраст и месячный лизинг.
Статья остаётся `draft: true` до проверки выводов на модели владельцем и решения о публикации.

## Воспроизвести

Из корня репозитория, в Python-окружении проекта:

```bash
python research/aircraft-prices-2026-11/analyze.py
python research/aircraft-prices-2026-11/build_report.py
```

Анализ работает без сети по сохранённым входам. Сборка создаёт `report.html` (RU),
`report.en.html` и `report.de.html`. Расчёт примера использует `flightcostapp.fleet`
и датированный снимок `research/_fx.json`; контрольные суммы входов записаны в результате.

Повторно извлечь возрастные колонки AVAC можно отдельной командой:

```bash
python research/aircraft-prices-2026-11/analyze.py \
  --refresh-avac --cache-dir /tmp/fca-aircraft-prices-avac
```

Каталог кеша должен находиться вне репозитория. Команда использует сохранённые там страницы
или скачивает их; сырые HTML не входят в исследовательский набор.

## Файлы и границы набора

- `SPEC.md` — вопросы исследования и правила сопоставления.
- `analyze.py` — покрытие, каталог к оценке, точные пары лизинга и стоимости, возрастные
  срезы, постоянный состав типов по годам и расчёт стоимости условного рейса.
- `out/summary.json` — расчётные результаты и контрольные суммы входов.
- `out/additional_observations.json` — отдельная исследовательская выписка.
- `out/sources.json`, `trace/prices.jsonl` — источники, даты, места в документах,
  ограничения и короткие цитаты для проверки.
- `verify/` — независимый пересчёт, проверка источников и журнал её охвата.
- `build_report.py`, `report*.html` — сборщик статьи и три языковые версии.

Исходный справочник содержит **167 принятых наблюдений по 22 типам**. Дополнительный
набор содержит **119 исследовательских наблюдений**: 102 возрастные ячейки AVAC
2016–2020 годов и 17 свежих ориентиров IBA (15 из авторской публикации ICLG и 2 из
официального подкаста). Это разные состояния данных; 119 строк не прибавляются автоматически
к принятому справочнику.

Публикация IBA относится к **2026-Q1**. Квартал сохранён как квартал, без выдуманного
месяца. Возраст, модификация и базис оценки сохраняются отдельно. Середина диапазона —
допущение сценария, а не наблюдаемая средняя цена сделки.

**Автоматического импорта нет.** Анализ и сборка не меняют `data/prices`, ставки
калькулятора и правила приёма черновиков. Новые данные требуют отдельного решения о
включении в справочник и корректного сохранения точности дат.

## Проверка

Независимая проверка завершена: пересчитаны исходные показатели, все 102 дополнительные
ячейки AVAC, 17 свежих ориентиров, 62 возрастных отношения, постоянный состав типов,
пары лизинга и стоимости, сквозной пример и цитаты. Итог — `pass_with_scope_limits`
в `verify/summary.json`; подробный охват и оговорки находятся в соседних файлах.
Этот статус подтверждает проверенные факты и арифметику; он не заменяет проверку
будущей возрастной модели и решение владельца о публикации.
