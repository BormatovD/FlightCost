# 0058 — публикация одной исследовательской статьи

**Новых страниц нет.** `research/index.yaml` меняет `draft` только у `aircraft-prices-2026-11`; `demand-2026-11` остаётся в черновиках.

## Что добавлено

- Видимый краткий ответ с датой оценок, источником, диапазонами и предупреждением, что лизинговая часть рейса не является полной стоимостью рейса.
- Перелинковка на уже существующие страницы A20N, A21N и калькулятор.
- Поисковые title/description, canonical и hreflang RU/EN/DE, Article и BreadcrumbList JSON-LD, OpenGraph.
- Три коротких вопроса в самой статье. **FAQPage JSON-LD не добавлен:** Google почти не показывает FAQ-rich-results обычным сайтам.
- Генератор `build_report.py` применяет `seo_article.py` после каждой повторной сборки HTML. Модуль идемпотентен и проверяет числовые источники, чтобы не публиковать устаревший блок после изменения данных.

## Проверка перед коммитом

```bash
python -m unittest discover -s research/aircraft-prices-2026-11 -p 'test_seo_article.py' -v
python -m py_compile research/aircraft-prices-2026-11/build_report.py research/aircraft-prices-2026-11/seo_article.py
```

## Проверка после деплоя

1. Открыть `/ru/research/aircraft-prices-2026-11` и проверить HTTP 200, блок ответа, формулы, ссылку на калькулятор.
2. Проверить исходный HTML: ровно один `<title>`, canonical на RU-адрес, hreflang RU/EN/DE; в английской и немецкой версиях — свои адреса.
3. Убедиться, что статья есть в `/ru/research` и в актуальном sitemap, а исследование спроса всё ещё скрыто как черновик.
4. В Google Search Console: проверить URL через «Проверка URL», запросить переобход после публикации; затем сравнивать показы, CTR и позиции **конкретной страницы** за сопоставимые периоды (28 дней и более), исключая влияние брендовых запросов.

**Никакой гарантии топ-5 SEO-разметка не даёт.** Не создавать дополнительные страницы с практически одинаковым содержанием ради ключевых слов. Числовые ориентиры пересматривать по мере поступления новых данных.
