# Спрос: что, кроме расстояния и жителей, решает, сколько людей летает между двумя городами

План работ: `research-demand`. Начато 10.11.2026.

## Зачем

Модель потока калькулятора (`traffic_model.py`, решение 214) — гравитация по массе аэропорта
и расстоянию. Она сама называет, чего не знает: туризма, поездов, хабов без статистики, городов с
несколькими аэропортами. Это исследование добавляет макрофакторы и проверяет, сколько каждый
даёт, — чтобы (1) оценивать поток пар без истории, включая новые, (2) давать паре профиль
сезонности, (3) получить «потенциал против предложения» — вход для коридора цен.

## Данные (все открытые, забирает `fca refresh`)

| Фактор | Источник в реестре | Уровень |
|---|---|---|
| Поток пар (ответ) | `eurostat_par`, `t100`, `dgca`, `ru_pairs` (домен `traffic`) | пара аэропортов, месяц |
| Жители вокруг аэропорта | `geonames_cities` | точка, 50–150 км |
| Доход | `wb_wdi` (страна), `eurostat_gdp_nuts3` (регион) | страна, NUTS 3 |
| Население региона | `eurostat_pop_nuts3` | NUTS 3 |
| Туризм, сезонность | `eurostat_nights_nuts2` (всего и нерезиденты), `wb_wdi` (прибытия) | NUTS 2 по месяцам, страна |
| Деловая активность | `eurostat_emp_nuts2` (финансы K, услуги M, N) | NUTS 2 |
| Диаспоры | `migrant_stock` (ООН) | пара стран |
| Визы | `visa_index` | пара стран |
| Привязка аэропорта к региону | `gisco_nuts3`, `gisco_nuts2` (центры регионов) | ближайший центр |

## Модель

ln(поток) = константа рынка + α ln(масса A · масса B) + β₁ ln(км) + β₂ ln²(км)
          + γ₁ ln(доход A · доход B) + γ₂ доля туризма + γ₃ доля деловых отраслей
          + γ₄ ln(1 + диаспора) + γ₅ виза + признаки: остров, скоростная ЖД, есть лоукостер.

Подгонка — по рынкам отдельно и вместе; проверка — на отложенных парах (как у проверки модели на
Frontier и Southwest), мера — медианная ошибка в разах и доля объяснённого разброса против
нынешней модели. Каждый фактор — с приростом точности, а не только с коэффициентом.

## Оговорки, которые пишутся в отчёт

* Предложение рождает спрос: приход лоукостера поднимает поток в разы — без признака модель
  выучит существующие рейсы как «потенциал».
* Рынок — город, а не аэропорт; поток по участкам (Eurostat, T-100) раздут хабами, чистые данные
  «откуда — куда» есть только в DB1C по США.
* Гравитация объясняет уровень, а не колебания следующего квартала.
