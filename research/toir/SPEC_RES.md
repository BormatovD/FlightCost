# Ставки резервов на ТО (maintenance reserves / supplemental rent) — задание исследователю

Зачем: у нас есть фактические расходы на ТО американских перевозчиков (Form 41) и расчёт «снизу» по каталожным ценам. Между ними
третья точка — **рыночная цена ТО со стороны лизингодателя**: ставки резервов, которые лизингополучатель платит за час/цикл/месяц,
чтобы покрыть будущие тяжёлые формы, капремонт двигателей, LLP, шасси, ВСУ.

Формат журнала — раздел «Журнал источников» в SPEC.md: `trace/<id>.jsonl`, в extract — дословная цитата (или строка таблицы как есть),
адрес, год документа. Не выдумывай: нет — `gap`. У каждой ставки обязателен год (ставки ежегодно индексируются) и тип ВС/двигателя.

## Что искать — ставки по составляющим

| Составляющая | Единица | Пример формулировки |
|---|---|---|
| Капремонт двигателя (performance restoration, PR) | USD за час работы двигателя (EFH) | «engine PR reserve of $XXX per EFH» |
| LLP двигателя | USD за цикл (EFC) | «LLP reserve $XXX per cycle» |
| Тяжёлая форма планера (C-check / 6Y / 12Y, airframe heavy maintenance) | USD в месяц | «airframe reserve $XX,XXX per month» |
| Шасси | USD за цикл или в месяц | |
| ВСУ | USD за час работы ВСУ (APU hour) | |

Также полезно: условия (тяга двигателя, соотношение часов к циклам, ежегодная индексация %), кто арендатор/арендодатель, год договора.

## Ответ сохраняй
`reserves/<id>.json`:
```json
{"items": [{"aircraft": "A320", "engine": "CFM56-5B", "component": "engine_pr|llp|airframe|landing_gear|apu",
            "value": 120, "unit": "USD/EFH|USD/EFC|USD/month|USD/APUH", "year": 2019, "escalation": 0.03,
            "conditions": "тяга, ratio, срок", "context": "кто/что", "evidence": ["l1-012"]}],
 "gaps": [], "doubts": []}
```
Проверь JSON. В ответе — сводка до 250 слов.
