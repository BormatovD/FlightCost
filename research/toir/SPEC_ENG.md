# Двигатели снизу: LLP и капремонт — задание исследователю

Строим стоимость ТОиР двигателя «снизу», чтобы сверить её с двигательной частью отчётности США (Form 41) и считать типы,
которых в США нет. Формат журнала — раздел «Журнал источников» в SPEC.md: `trace/<id>.jsonl`; в extract — дословная цитата
(или строка таблицы как есть), адрес, год публикации. Не выдумывай: нет — `gap`. Числа без года цены бесполезны — год обязателен.

## По каждому двигателю из твоего списка

1. **Применение**: на каких типах ВС (коды ИКАО), сколько двигателей на борту, диапазон тяги (модификации).
2. **LLP** (детали с ограниченным ресурсом):
   - перечень модулей/дисков и их ресурс в циклах (EFC) — если опубликован; минимум — ресурс «лимитирующего» LLP и типичный ресурс комплекта;
   - **каталожная цена полного комплекта** (full LLP shipset / stack) — с годом каталога и издателем;
   - **ежегодный рост каталожных цен** (escalation) — по годам, если есть (CFM, IAE, P&W, GE, RR объявляют ежегодно, пресса пишет).
3. **Капремонт** (shop visit, performance restoration):
   - интервал до первого и между последующими ремонтами — в часах (EFH) или циклах (EFC), с указанием, при каком соотношении часов к циклам (длина сектора) и при какой тяге;
   - **стоимость ремонта** (без LLP и с LLP — уточни, что включено), с годом;
   - если есть — типичная ставка резервов лизингодателю за час (USD/EFH) и за цикл для LLP (USD/EFC).
4. Особые факторы: известные проблемы долговечности (GTF — порошковая металлургия, LEAP — лопатки ТВД, Trent 1000), гарантии/компенсации, если влияют на стоимость.

## Источники по порядку
Производители двигателей (пресс-релизы, каталоги), открытые статьи Aircraft Commerce (PDF по прямым ссылкам — ищи «Aircraft Commerce
<двигатель> maintenance analysis / budget», «LLP list prices»), отраслевая пресса (AviTrader MRO, Aviation Week, FlightGlobal, Leeham News),
оценщики и лизингодатели (ICF, IBA, mba, Avitas — открытые отчёты; проспекты секьюритизаций ABS на SEC с разделами о двигателях),
для российских двигателей — ОДК, «Авиадвигатель», «ПД-14», «SaM146» (PowerJet), прессa (ATO.ru, «Авиация России»), госзакупки.
