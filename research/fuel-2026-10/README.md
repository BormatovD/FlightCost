# Стоимость авиатоплива: регионы мира и Россия, октябрь 2026

Вопрос: насколько цена топлива «в крыло» в регионах отличается от спота USGC, на котором сейчас считает калькулятор,
и какую поправку ввести. **Отчёт — `report.html`** (сборка: `python3 research/fuel-2026-10/build_report.py`).

- `SPEC.md` — задание исследователю, `JOURNAL.md` — формат журнала, `VERIFY.md` — задание проверяющему.
- `trace/f1.jsonl` (мир), `trace/r1.jsonl` (Россия) — журналы поиска с дословными цитатами; `verify/f1.json`, `verify/r1.json` — проверка отдельными агентами.
- `SPEC_RU.md` — задание по России; `out/ru.json` — итог по России (цены ТЗК, биржа, демпфер, налоги, модель).
- `out/fuel.json` — итог исследователя (регионы, налоги, надбавки, проверка по авиакомпаниям, пробелы, сомнения).

Статья — по структуре `../STYLE.md`. Предложение для модели после проверки — таблицы `MODEL` и `GROUPS` в `build_report.py`: множитель «в крыло» к USGC по регионам
с диапазоном и уверенностью; Индия и Россия — своими рядами. В модель ещё не введено.
