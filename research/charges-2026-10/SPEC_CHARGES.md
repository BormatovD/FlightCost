# Аэропортовые сборы — задание исследователю

Проект FlightCostApp считает экономику авиарейса; сборы аэропорта берутся из опубликованного тарифа, разложенного
по закрытой схеме правил. Твоя задача — для каждого аэропорта из твоего списка найти действующий опубликованный
тариф (документ оператора аэропорта, регулятора или AIP GEN 4.1), разложить его в JSON проекта и проверить.
**Точность важнее полноты:** пропуск безопасен, выдумка — нет. Не подставляй ставки соседнего аэропорта.

Пути (читать, НЕ менять): репозиторий `R=gh3`.
Рабочая папка: `W=charges`.

## Прочитать перед работой
1. `$R/skills/SKILL-collect-charges.md` — порядок работы и пять частых ошибок. Следуй ему.
2. `$R/flightcostapp/charges.py` — `BASES`, `EVENTS`, `CONDITION_KEYS`, `DOMAINS` (ступени `dest`, значения `flight`) с
   комментариями: допустимо только это.
3. Образцы готовых файлов в `$R/data/charges/`: `LOWW-2026.json` (Европа, группы стоянок), `EIDW-2026.json`,
   `LEBL-2026.json` (сеть Aena), `LPPR-2026.json` (сеть ANA, полосы массы `per_tonne_above`), `VIDP-2025.json`,
   `VOBL-2026.json` (Индия, ордера AERA, `per_tonne_hour_above`), `OTHH-2026.json` (Залив), `EGKK-2026.json` (фунты).
   Файлы с `_` в начале — заметки по режимам регулирования; `_todo.yaml` — найденные адреса.
4. Раздел «Журнал источников» в `toir/SPEC.md`
   — формат журнала.

## Что сдать по каждому аэропорту
- `$W/out/<ICAO>-<год действия>.json` — файл тарифа по образцам: `icao`, `valid_from`, `source`, `source_url`
  (обязателен — прямой адрес документа), `publisher`, `checked_at`, `rules`. Ставки — в валюте документа с полем
  `currency`, без пересчёта. У каждого правила `source_note` — раздел/таблица документа.
- Проверка: `python3 $W/bin/check.py $W/out/<файл>.json` — парсер проекта и контрольный оборот A320 (148 пасс.)
  из Франкфурта. Исправляй, пока парсер не принимает файл без отвергнутых правил, а оборот не попадает в разумный
  коридор режима (в выводе скрипта). Если не попадает и ошибка не находится — оставь как есть и опиши в отчёте.
- Журнал `$W/trace/<твой id>.jsonl`: search / open / extract / reject / conclude / gap. В `extract` — дословная
  цитата строки или ячейки тарифа (с подписью столбца), по которой взята ставка; одна цитата может покрывать
  несколько ставок одной таблицы. Цитаты проверит отдельный агент.
- Если документа не нашлось после 3–4 разных запросов — строка `gap` с тем, где искал, и без файла.

## Источники по порядку
Сайт оператора аэропорта (Airport Charges / Conditions of Use / Entgeltordnung / Tarifas / Tariffe / Redevances),
решения регулятора (Индия — AERA tariff orders и Tariff Cards; ЮАР — ACSA Permission/Tariff; Египет, Кения, Нигерия —
сайты операторов и AIP), национальный AIP GEN 4.1 (eAIP), сводки IATA или ACI — только как указатель.
Сеть с одним документом (Aena — все аэропорты Испании, ANA — Португалии, ACSA — ЮАР, AAI — государственные аэропорты
Индии, ONDA — Марокко, FAAN — Нигерия): если документ уже разобран для другого аэропорта сети (см. `$R/data/charges`),
используй тот же адрес, но ставки бери для СВОЕГО аэропорта/группы.

В ответе — сводка до 200 слов.
