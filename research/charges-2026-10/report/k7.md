Итог: **файлов 0, шесть gap**. Утверждённой тарифной карты, которую можно прочитать, не нашлось ни для одного аэропорта. Ставки из предложений операторов и из новостей не заводил.

## Почему не получилось
- Через прокси закрыты curl к aera.gov.in, adani.com, aai.aero, investor.gmraero.com (403). WebFetch открывает только адреса, которые пришли из поиска.
- По списку ордеров AERA WebFetch отдаёт кэш 2020–2024 без ссылок на PDF.
- В ордерах AAI 3-го КП (Пуна 45/2021-22, Гоа 04/2022-23) текстовый слой есть только на первых ~30 страницах. Аннексы с тарифной картой отсканированы, WebFetch их не распознаёт. Браузера Chrome в сессии нет.
- В индексе AIC (eAIP India) видно, где опубликованы тарифы: AIC 8/2022 (Пуна), 11/2022 (Гоа), 8/2023 (Лакхнау, 22.06.2023), 14/2023 (Мопа, 29.12.2023), 10/2024 (Джайпур, 31.07.2024), 12/2024 (Гувахати, 13.09.2024). Через поиск сами файлы не находятся, а прямые адреса вне allowlist.
