# Исследования

Каждое исследование — своя папка: задания исследователям, журналы поиска с цитатами, проверка цитат отдельными
агентами, итоговые данные и отчёт. Сырые данные (CSV, PDF) не хранятся — откуда и как их взять, сказано в журналах.

| Папка | Что | Отчёт |
|---|---|---|
| [`toir/`](toir/) | Ставки ТОиР по типам ВС (Form 41, 1991–2025), рост ТОиР против инфляции, экономика послепродажного рынка производителей двигателей, каталог против факта | [`toir/report.html`](toir/report.html), журнал — [`toir/README.md`](toir/README.md), карта поиска — `toir/map.html` |
| [`fuel-2026-10/`](fuel-2026-10/) | Цена авиатоплива «в крыло» по регионам к споту USGC, налоги и примеси, исключения (Индия, Россия) | [`fuel-2026-10/report.html`](fuel-2026-10/report.html) |
| [`hothigh-2026-10/`](hothigh-2026-10/) | Жара и высота аэродрома: ограничение взлётной массы, поправка для модели | [`hothigh-2026-10/report.html`](hothigh-2026-10/report.html) |
| [`charges-2026-10/`](charges-2026-10/) | Аэропортовые сборы 50 аэропортов Европы, Индии и Африки: 32 тарифа в `data/charges/`, ненайденное — в `data/charges/_todo.yaml` | [`charges-2026-10/report.html`](charges-2026-10/report.html), журнал — [`charges-2026-10/README.md`](charges-2026-10/README.md) |

| Что | Статус |

## Публикация на сайте

Раздел «Исследования» (`/<язык>/research`, лента Atom — `/research/feed.xml`) читает `index.yaml`: новое
исследование — строка сверху с папкой, путём к отчёту HTML и подписями на трёх языках. Отчёт публикуется как есть —
сервер добавляет только шапку сайта, канонический адрес, описание и значок; файл должен быть самодостаточным
(стили и шрифты сайта вшиты, как в `toir/build_report.py`). Выкладка — обычный `git push`: сервер берёт `research/`
из репозитория.

Как устроен журнал поиска (`trace/*.jsonl`): шаги search · open · extract · infer · reject · conclude · gap; у каждого
`extract` — короткая дословная цитата источника, по которой взята цифра. Цитаты в журналах — короткие фрагменты для
проверки происхождения цифр; права на тексты — у издателей.
