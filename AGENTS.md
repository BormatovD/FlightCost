# UI и типографика

- Следовать существующему UI проекта, его шрифтам, размерам текста и визуальной иерархии.
- Для однотипных элементов в одном блоке использовать общие CSS-правила. Не создавать отдельные подходы к шрифту для каждого поля или устройства без необходимости.
- В выборе авиакомпаний сохранять единый размер шрифта полей на компьютере и телефоне; удобство касания обеспечивать высотой элемента и отступами.
- Сохранять авторскую логику повествования и порядок блоков. Изменение структуры или логики предварительно согласовывать с пользователем.

# Тестовые HTTP-запросы

- Помечай тестовые запросы к FlightCost параметром URL `probe=dev`, в том числе POST и запросы браузерных сценариев. Это относится к smoke-тестам, нагрузочным прогонам и замерам на публичной витрине.
- В Python используй `flightcostapp.probe.probe_url`. Для ручной проверки калькулятора открывай `/ru/calc?probe=dev` и сохраняй метку в адресе проверяемой страницы. Метку передавай только сервисам FlightCost.
- При анализе журнала отделяй помеченные запросы. Среди остальных могут быть обычные посещения и проверки без метки.
