# Замечания по интерфейсу

Подписи, пояснения и места, где новому человеку непонятно. Одна строка — одно замечание.

**Как вести**

- **Где** — страница → блок → строка. Пример: «Расчёт → Бенчмарк → верхняя строка». Страницы: Расчёт, Сеть, Отчёт по парку (сайт / PDF / Excel), Карта данных, Данные.
- **Почему** — самая важная колонка. По ней находятся такие же места в других частях: та же подпись часто стоит и на сайте, и в отчёте, и в Excel.
- **Статус:** `новое` → `в работе` → `устранено` (в комментарии — решение ROADMAP или дата архива) · `отклонено` (с причиной) · `обсудить`.
